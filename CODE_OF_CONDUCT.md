# Codigo de conduta

Este projeto adota o [Contributor Covenant, versao 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, presuma boa-fe, mantenha as discussoes sobre o trabalho
e nunca assedie ninguem. Reporte comportamentos inaceitaveis de forma privada ao
mantenedor pelo GitHub (ThiagoVenturim). Os relatos sao tratados com sigilo.
